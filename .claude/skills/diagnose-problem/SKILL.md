# diagnose-problem


## Purpose

Identify confirmed root causes before fixing issues.

## Instructions

1. Reproduce issue consistently.
2. Characterize behavior.
3. Isolate failing subsystem.
4. Form explicit hypothesis.
5. Test hypothesis.
6. Confirm root cause before fixing.

## Debugging Checklist

- [ ] Reproduction confirmed
- [ ] Logs collected
- [ ] Root cause verified
- [ ] Evidence documented
- [ ] Regression risk evaluated

## Example

Input:
Intermittent API 500 errors.

Expected behavior:
- Reproduce under concurrency
- Isolate race condition
- Confirm shared state issue
