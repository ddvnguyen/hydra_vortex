# design-solution


## Purpose

Create implementation plans before modifying code.

## Instructions

1. Identify affected components.
2. Describe data flow.
3. List alternatives considered.
4. Flag irreversible changes.
5. Estimate implementation scope.
6. Produce implementation order.

## Design Checklist

- [ ] Files identified
- [ ] Risks documented
- [ ] Rollback possible
- [ ] Dependencies identified
- [ ] Tradeoffs explained

## Example

Input:
Add JWT authentication.

Expected behavior:
- Middleware plan
- Token lifecycle design
- Risk analysis
